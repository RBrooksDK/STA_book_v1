# Data

Datasets used in worked examples and Python sections belong here. For every
file, record its origin, licence, variables, units, and any preprocessing or
synthetic generation procedure in the chapter source register.

`sensor_thickness.csv` is the reproducible synthetic dataset used in Chapter 1.
It is generated in the STA1 course repository with NumPy
`default_rng(2026)` and contains 180 plate measurements in micrometres.
